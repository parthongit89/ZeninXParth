About ZeninXParth

Vision & Origins

ZeninXParth represents the joint engineering synergy between Ghostofzenin08 (Harshal Sonawane) and Parthongit89 (Parth Sonavane). Combining high-performance Python/Pygame game loops with cutting-edge web engineering, cloud score persistence on Neon PostgreSQL, and real-time Google Firebase Authentication.

Full-Stack Prompt Engineering Strategy

Architected in accordance with our standardized prompt-engineering framework (Project-Strategies-Prompt-engineering-). Every system balances lightweight client efficiency, robust serverless backend scaling, and pixel-true aesthetic execution.

Core Technology Ecosystem

• Engines: Python 3.11, Pygame, Vanilla ES6+ WebGL / HTML5
• Backends: Flask 3.0 WSGI, Gunicorn, Flask-CORS, SQLAlchemy
• Database & Cloud: Neon Serverless PostgreSQL, Render Production Hosting, itch.io Web Bundles
• Auth & Security: Google Firebase Authentication v10+ with OAuth & JWT verification
• Design System: Instrument Sans typography, deep-black cyberpunk glassmorphism, responsive CSS variables
